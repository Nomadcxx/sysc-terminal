# AK-47 braille animation

Owner approved this design on 2026-10-12. Tracker: sysc-terminal-9.

Render Lokeig's actual AK-47 mesh as shaded braille surface points. Begin
side-on, centered, with theme colours and physical cell aspect preserved.
Rotate twice in eight seconds, swirl the points outward over two seconds,
then reconstruct the rifle over two seconds. Repeat without a visible jump.

Implement the effect once in sysc-Go and expose `ak-47` through the registry,
CLI, TUI and sysc-terminal constructor. Reuse logo braille composition and
palette data. Use UpdateElapsed for active time, nominal 50 ms Update for
other hosts, pure Render, phase-preserving resize and reset to frame zero.

Convert the supplied binary FBX once with Go standard library code. Validate
its version, lengths, indices, transforms and finite coordinates; reject
unsupported source changes. Bake at most 24000 surface samples with positions
and normals. Runtime reads only embedded compact data. No textures, runtime
FBX parser, new dependencies, timers or goroutines.

Source: "AK-47" (https://skfb.ly/oyAsI) by Lokeig, Creative Commons
Attribution-NonCommercial 4.0 (https://creativecommons.org/licenses/by-nc/4.0/).
The source page confirms the version. Model-derived data retains that license;
repository code licensing does not relicense it. Include attribution and list
changes: coordinate normalization, surface sampling, braille shading and morph.

Check the two-turn boundary, exact reconstruction, render purity, elapsed-time
equivalence, reset, resize and pause. Review full loops at 491x90 and 365x90,
plus 80x24. Retain existing CPU limits: 12.5 ms at blur 0 and 30 ms at blur 64,
RSS below 150 MiB and ten-minute growth below 10 MiB. Keep current wallpaper
assignments intact while producing headless previews. Upstream library must
be available before the final engine module pin can resolve remotely.
