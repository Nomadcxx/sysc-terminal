# AK-47 Implementation Plan

**Goal:** Add the approved two-turn, swirl, reconstruction braille animation.

**Architecture:** Bake bounded surface samples from the supplied FBX using Go.
Implement animation and registry in sysc-Go; sysc-terminal owns host integration.
Reuse existing logo palette and braille composition, plus active elapsed time.

**Tech Stack:** Go standard library and existing sysc-Go/raster dependencies.

1. Add `cmd/bake-ak47/main_test.go` in sysc-Go, proving malformed/truncated
   FBX rejection and supplied mesh conversion. Run the named check, observe
   failure, then implement `cmd/bake-ak47/main.go`. Preserve source digest and
   license in `animations/models/README.md`, bake compact `ak47.bin`.
2. Add `animations/ak47_test.go` for two turns before morph, exact loop,
   deterministic rendering, bounded dimensions and timing. Observe failure;
   implement `animations/ak47.go` using existing logo buffer composition.
   Register in `animations/registry.go`, `cmd/syscgo/main.go`, `tui/animfactory.go`.
3. Add `TestAK47Lifecycle` in engine `internal/effect/effect_test.go`. Observe
   missing effect failure; add constructor and cell-aspect dispatch. Use a local
   untracked Go workspace for paired development. Extend existing pipeline
   budget sampling to cover the entire 12-second cycle.
4. Run named checks using `timeout 90s env CGO_ENABLED=0 GOMAXPROCS=2 go test
   -count=1 <package> -run <Name>`. Generate headless complete-loop previews,
   inspect silhouette, reconstruction and both turns, run frame budget at blur
   0/64, review diffs and record evidence. Retain a reproducible local build if
   upstream publication has not occurred; never leave a local replace in go.mod.
